# 本地交付验证

WinPlay 1.2.3-ui.1 操作体验定制版

使用方法
1. 将 Windows-x64.zip 完整解压到普通文件夹，双击其中的 WinPlay.exe。不要在压缩包内部运行。
2. 关于 → 认证文件 → 导入认证文件，同时选择找回的 identity.pk8 和 certificate.p7b。
3. 按连接页的步骤完成蓝牙配对、准备移动热点或局域网，再点击启动接收。

本次已从你提供的 WinPlay-1.2.3-Setup-x64.exe 中找回两个认证文件，并用程序的 validateAuthentication 校验其格式与公钥匹配。认证文件单独保存在“WinPlay认证文件”目录和同名 ZIP 中，没有混入源码包。

主要变化
- 连接页分步排列，增加首次认证入口、密码显隐和高级网络设置折叠。
- 语言、主题和关闭行为移到“关于 → 应用”。
- 连续点击防重入，启动准备可取消，运行中 Enter 不再重启。
- 刷新网卡保留手动选择；设置保存失败阻止误启动。
- 明确提示哪些已保存设置需要重连，蓝牙检测错误在页内显示。

验证情况
- 最终自动化回归：249 项通过。Windows 系统媒体控件集成测试曾因环境拒绝访问失败，最终回归单独排除了该测试，未声称其通过。
- 最终打包程序的 Electron 离线自测：36 项通过，包括页面、语言、主题、窗口、合成视频与音频。
- 为适应受限执行环境，桌面自测使用了 --self-test --no-sandbox --disable-gpu 参数；交付程序没有永久关闭 Chromium 沙箱，也没有要求日常使用这些参数。普通启动及安装流程未在非受限桌面验证。
- 已核对 app.asar 中修改文件与源码一致，并检查 ZIP 可完整解压。
- 尚未用真实 iPhone 验证蓝牙连接、热点及 CarPlay 认证。文件匹配不等于 iPhone 端认证必然通过。

交付说明
这是解压即用版，已包含 Electron、Node.js 和原生组件，无需另装开发环境。传统 NSIS 安装器编译工具在当前 Windows 环境无法执行，因此未交付 Setup.exe。
用户设置与配对数据仍保存在原来的 %APPDATA%\WinPlay\data，替换前请退出旧版。
这是基于 Roylyl/WinPlay 1.2.3 的本地定制版，非上游官方发行版。源码包保留原始许可证与版权声明。

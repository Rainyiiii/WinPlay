# WinPlay 1.2.3-ui.1 操作体验定制版

基于 Roylyl/WinPlay 1.2.3 源码修改，不是上游官方发行版。

## 操作流程与布局

- 连接页按“配对并选择 iPhone → 准备无线网络 → 启动 CarPlay”组织。
- 蓝牙设置与刷新设备放在一起；网络读取放在手动输入之前。
- 网络接口、信道和 BSSID 收入高级设置；支持显示或隐藏密码。
- 语言、外观和关闭行为移到“关于 → 应用”。
- 缺少认证文件时，首页提供入口；点击启动会定位到导入区域。
- 修改连接、显示或音频设备后，提示设置已经保存、重连后生效；音量和主题等即时设置不会触发这个提示。

## 操作逻辑修复

- 连续点击启动只提交一次操作；等待设置保存或音频准备时也能取消，取消后不会延迟启动。
- 正在启动时锁定连接参数，避免启动读到半套新配置。
- 运行中按 Enter 不再重新连接；中文输入法组合输入也不会意外启动。
- 刷新网卡不再自动清空暂不可用的手动选择。
- 保存失败会保留错误状态，阻止用旧配置误启动；显示设置响应按最新请求更新。
- 局域网必填信息检查失败时定位输入项；热点仍允许在启动时读取 Windows 配置。
- IPC 异常转成可见提示，避免按钮一直处于忙碌状态。

## 构建

使用 Node.js 24.19.0、Electron 42.11.10。依赖锁文件重新生成，PowerShell 脚本改为 UTF-8 BOM，兼容系统自带 Windows PowerShell。

```powershell
npm ci
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/fetch-runtime.ps1
npm run build
npm test
npx electron-builder --win nsis --x64
```

本地 ui.2 包已内置找回的匹配认证文件，无需另行导入。原有用户数据路径与上游一致，升级前退出正在运行的 WinPlay。本版本未签名。

自动化测试和合成媒体自测不能替代真实 iPhone 的蓝牙、热点及 CarPlay 认证测试。实际连接仍取决于设备、网络和认证文件。
